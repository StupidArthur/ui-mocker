# 测试记录：Data-Algorithm Studio

> 流程阶段④产出。测试核心业务逻辑（不依赖 FastAPI runtime 的纯逻辑）。

## 运行

```bash
cd backend
python -m pytest -v
```

## 环境隔离

`tests/conftest.py` 在导入业务模块前设置环境变量 `STUDIO_DATA_DIR` 到 `tempfile.mkdtemp()`，
使数据库与上传/派生文件全部写入临时目录，不污染真实的 `backend/data`。

## 端到端（API 级）

额外以 `TestClient` 跑通完整业务闭环（临时数据目录）：

注册 → 上传数据集 → 建项目 → 根节点 → 执行统计并审核通过 → 子节点执行预测并审核通过
→ 公开项目 → 他人克隆（校验节点复制）→ 越权删除被拒 → 管理员重置密码 → 改密 → 驳回流程。

结果：**通过**。
