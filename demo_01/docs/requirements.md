# 需求文档：Data-Algorithm Studio（UI 自动化测试演示站）

> 流程阶段①产出。用于 AI-based UI 测试自动化的案例调试，追求端到端逻辑闭环可点通，不追求生产完备性。

## 1. 背景与目标

构建一个前后端分离的演示网站「Data-Algorithm Studio」，用于 UI 自动化测试案例的编写与调试。
核心链路：注册/登录 → 上传时序数据集 → 创建项目 → 在数据集上执行算法 → 审核算法结果 → 沉淀血缘节点 → 基于节点继续执行 → 公开/克隆项目。

## 2. 角色

| 角色 | 权限 |
|------|------|
| 普通用户 | 管理自己的数据集与项目；可公开自己的项目；可克隆公开项目 |
| 管理员 | 拥有普通用户全部能力；额外可查看用户列表、创建账号、重置任意用户密码、公开任意项目 |

## 3. 功能需求

### 3.1 认证与用户（FR-AUTH）

- FR-AUTH-1 用户可注册（用户名 + 密码）。
- FR-AUTH-2 用户可登录、登出。
- FR-AUTH-3 用户可修改自己的密码。
- FR-AUTH-4 管理员可创建账号（指定用户名、密码、角色）。
- FR-AUTH-5 管理员可重置任意用户密码。
- FR-AUTH-6 管理员可查看用户列表。

### 3.2 数据集（FR-DATA）

- FR-DATA-1 数据集为时序数据：行=时间轴，列=位号名，单元=值。
- FR-DATA-2 支持上传 CSV 与 Parquet 文件。
- FR-DATA-3 数据集按用户隔离，仅所有者与管理员可见/操作。
- FR-DATA-4 支持列表、查看详情（行列数、列名、时间列、大小）、预览（前 N 行 + 统计摘要）。
- FR-DATA-5 支持删除数据集。

### 3.3 项目（FR-PROJ）

- FR-PROJ-1 用户可创建项目，项目绑定**一个数据集**，加载后形成**唯一血缘根节点**。
- FR-PROJ-2 项目默认私有，仅所有者与管理员可见。
- FR-PROJ-3 所有者或管理员可将项目设为公开/取消公开。
- FR-PROJ-4 公开项目对所有登录用户可见。
- FR-PROJ-5 用户可将公开项目克隆为自己的副本（数据集引用与血缘一并复制）。
- FR-PROJ-6 支持项目列表（我的 / 公开）、查看、编辑名称与描述、删除。

### 3.4 项目工作区与血缘（FR-LINEAGE）

- FR-LINEAGE-1 项目内可查看血缘树（单根）。
- FR-LINEAGE-2 血缘节点 = 数据集当前状态 + 该状态上的属性（统计指标 / 派生列）。
- FR-LINEAGE-3 可在任意血缘节点上执行算法，产出算法结果。
- FR-LINEAGE-4 算法结果可展示（结果详情 + 数据预览）。
- FR-LINEAGE-5 算法结果可审核：通过 / 驳回。
- FR-LINEAGE-6 审核通过的结果沉淀为新的血缘节点，可在其上继续执行算法，形成血缘树。
- FR-LINEAGE-7 算法结果可删除。
- FR-LINEAGE-8 算法类型（真实计算）：
  - 统计类：描述性统计（均值/方差/最值/缺失率）、相关系数、趋势斜率。
  - 预测类：移动平均平滑、线性回归外推。
- FR-LINEAGE-9 算法结果附带派生数据文件，供后续算法继续计算。

## 4. 非功能需求

- NFR-1 存储：元数据 SQLite，上传文件与派生数据落本地目录，重启不丢。
- NFR-2 后端：Python + FastAPI，RESTful，自动 OpenAPI 文档。
- NFR-3 前端：React 18 + TypeScript + Vite + Tailwind v3 + Shadcn UI，Notion 式浅色简约风。
- NFR-4 核心业务逻辑（算法、血缘、数据解析）可独立于框架测试。

## 5. 非目标（Out of Scope）

- 组织 / 多租户、计费、消息通知。
- 生产级算法平台、外部数据源接入、文件版本控制。
- 邮箱验证、找回密码邮件、第三方登录。

## 6. 验收主链路

注册 → 登录 → 上传 CSV → 创建项目 → 查看根节点 → 执行统计算法 → 审核通过 → 生成子节点 → 在子节点上执行预测算法 → 审核通过 → 公开项目 → 另一账号登录克隆 → 管理员重置某用户密码。
